## Virtual Library Application
A Java command-line application for managing a virtual library. The project uses object-oriented design and custom data structures to organize, search, sort, and persist different types of literature.

### Overview
The application supports multiple types of literature, including novels, magazines, and poetry. Users can add, remove, search, sort, and organize items into custom categories. 

### Implementation
- Designed a class hierarchy using inheritance for different types of literature
- Implemented binary search trees to organize literature by title, author, and publication date
- Implemented a linked list to maintain the library collection and order items by date added
- Added search and sorting functionality through the different data structures
- Implemented custom categories for organizing literature
- Used Java serialization to persist the library between program sessions
- Added input validation and error handling for invalid user input

### What I Learned
As my first substantial software project, this gave me a foundation in object-oriented design and working with data structures beyond the standard library. I learned how data structures can be designed around specific operations, such as using separate binary trees to efficiently organize and search the same collection in different ways. It also gave me experience designing a larger program as multiple interacting classes rather than a single piece of code.
